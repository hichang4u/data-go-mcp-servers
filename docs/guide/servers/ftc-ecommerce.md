# 공정거래위원회 통신판매사업자 (ftc-ecommerce)

온라인으로 물건을 파는 사업자는 통신판매업 신고 의무가 있다. 이 서버는 그 신고 내역을 **사업자등록번호로 바로** 조회한다 — 신고번호·신고일·신고기관, 영업상태, 도메인, 취급품목, 대표자와 연락처.

## 인증키

data.go.kr 공통 `API_KEY` 를 쓴다. [통신판매사업자 등록상세 제공 서비스](https://www.data.go.kr/data/15126315/openapi.do)에 활용신청이 필요하다 (자동 승인). 신청 전에는 `data.go.kr 오류 [30]` 이 난다.

## 사업자번호로 조회하기

```
> 120-88-00767 통신판매 신고돼 있어?
  쿠팡주식회사 · 정상영업 · 신고 2026-서울광진-1253 (2013-08-21) · 종합몰
  도메인 http:/www.coupang.com, http://www.coupangeats.com
```

**법인등록번호(`corporate_number`)가 함께 온다.** 금융위 재무 툴은 사업자번호가 아니라 법인등록번호(`crno`)로 조회하므로, 이 값을 `get_corp_outline` 이나 재무제표 툴에 그대로 넘기면 된다 — 사업자번호에서 재무로 가는 또 하나의 길이다.

## 알아둘 것

- **상호로는 조회할 수 없다.** 문서에는 상호 조회가 있다고 나오지만 실제로는 무시된다 — `bzmnNm`·`cmpnm`·`entrpsNm`·`corpNm` 어느 것을 보내도 전체 2,758,879건이 돌아온다 (2026-10-03 확인). 그래서 툴은 사업자번호나 신고번호 중 하나를 반드시 받는다.
- 빈 값이 `null` 이 아니라 **`"N/A"` 문자열**로 온다. 툴이 `None` 으로 바꿔 준다.
- **신고하지 않은 사업자는 0건**이다. 오류가 아니다 — 온라인 판매를 하지 않는 회사가 대부분 여기 해당한다.
- 영업상태는 `정상영업`·`직권말소`·`직권취소` 등이고, 사업자 상태(`business_status`)는 국세청 기준의 `계속사업자`/`폐업자` 다. 둘은 별개로 움직인다 — `active` 는 영업상태 기준이다.
- 폐업한 사업자는 법인등록번호가 `"N/A"` 로 비어 오는 일이 잦다.
- 신고번호 형식은 지자체마다 다르다 (`2026-서울광진-1253`, 옛 건은 `1137` 처럼 숫자만).

### `get_online_seller`

통신판매업 신고 내역을 조회합니다. Look up a mail-order (e-commerce) seller registration.

온라인으로 물건을 파는 사업자는 통신판매업 신고 의무가 있습니다. 신고번호·신고일·신고기관,
영업상태(정상영업/직권말소/직권취소), 도메인, 취급품목, 대표자와 연락처가 나옵니다.
**법인등록번호(corporate_number)가 함께 오므로** 기업 재무제표 조회로 바로 이어집니다.

사업자번호 또는 신고번호 중 하나가 필요합니다. **상호로는 조회할 수 없습니다** — API 가
상호 파라미터를 무시하고 전체를 돌려줍니다. 신고하지 않은 사업자는 0건입니다.

| 파라미터 | 타입 | 필수 | 기본값 | 설명 |
|---|---|---|---|---|
| `business_number` | string (optional) |  |  | 사업자등록번호 10자리 (예: 120-88-00767 또는 1208800767) |
| `report_number` | string (optional) |  |  | 통신판매업 신고번호 (예: 2026-서울광진-1253). 사업자번호 대신 쓴다 |
| `num_of_rows` | integer |  | `10` | 한 페이지 결과 수 (기본값: 10, 최대: 100) |
| `page_no` | integer |  | `1` | 페이지 번호 (기본값: 1) |
