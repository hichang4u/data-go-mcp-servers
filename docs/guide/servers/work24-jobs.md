# 고용24 채용정보 (work24-jobs)

고용24(옛 워크넷)의 채용공고를 **사업자등록번호로 바로** 조회한다. 어떤 회사가 지금 어떤 자리를 얼마에 뽑는지, 그리고 상세에는 그 회사의 종업원 수·자본금·연 매출액까지 들어 있다.

## 인증키

data.go.kr 이 아니다. 포털에 "한국고용정보원_워크넷 채용정보"가 있지만 등록유형이 **LINK** 라 공통 `API_KEY` 로는 호출되지 않는다 (엔드포인트가 `www.work24.go.kr`).

[www.work24.go.kr](https://www.work24.go.kr) → 오픈API → **서비스별로 신청**한다. 환경변수는 `WORK24_API_KEY` — [api-keys.md](../api-keys.md) 6절.

신청하지 않은 서비스를 부르면 이렇게 온다:

```
고용24 오류 [] 신청하신 OpenApi 서비스가 존재하지 않습니다
```

이 서버는 **채용정보**만 쓴다. 같은 포털의 채용행사·공채속보·임금체불 명단은 각각 따로 신청해야 하며 아직 쓰지 않는다.

## 예시 프롬프트

- "사업자번호 503-81-69211 이 지금 채용 중이야?"
- "강남구에서 연봉 4천만원 이상 공고 보여줘"
- "이 공고 상세 내용이랑 자격요건 알려줘"

## 알아둘 것

- **사업자등록번호로 필터된다.** 나라장터 낙찰과 달리 기간을 훑지 않고 한 번에 조회된다 — 국세청·금융위·근로복지공단 조회와 같은 번호로 이어진다.
- **조건을 하나도 주지 않으면 전국 공고 전체**(5만 건 이상)다. 그래서 툴이 사업자번호·검색어·지역·직종·최저임금 중 하나를 요구한다.
- 지역코드는 **법정동코드 앞 5자리와 호환**이다 (`11680` 강남구). nps 의 `find_region_code` 결과를 10자리 그대로 넣어도 된다. 시도 전체도 된다 (`11000` 서울).
- **파라미터 이름을 틀리면 조용히 전국이 온다.** `busiNo`(대소문자), `regionCd`, `empTpCd` 는 무시된다 — 클라이언트가 올바른 이름으로만 보낸다.
- 한 페이지 최대 **100건** (그 이상을 줘도 100건).
- `keyword` 는 공고 전반을 훑는다. 회사명으로 쓰면 무관한 공고가 섞이니 사업자번호가 정확하다.
- 상세 조회에는 `infoSvc`(정보제공처)가 필수다. 목록 결과의 `info_service` 를 그대로 넘기면 되고, 기본값은 `VALIDATION` 이다.
- 임금은 원 단위이며 `max_salary` 가 0이면 상한 미지정이다. 종업원 수·자본금·매출액은 `"25 명"`, `"453 백만원"` 처럼 단위가 붙은 문자열로 온다 (원문 그대로 둔다).

### `get_job_posting`

채용공고 상세를 조회합니다. Get one job posting in full.

담당 업무·자격증·전공·우대조건과 함께 **기업 정보(종업원 수, 자본금, 연 매출액, 기업 규모)**를
돌려줍니다. 비상장 회사는 금융위 재무정보에 없는 경우가 많아, 여기가 규모를 알 수 있는
유일한 공개 자료일 때가 있습니다.

| 파라미터 | 타입 | 필수 | 기본값 | 설명 |
|---|---|---|---|---|
| `wanted_auth_no` | string | 예 |  | 채용공고 번호 (search_job_postings 의 wanted_auth_no) |
| `info_service` | string |  | `VALIDATION` | 정보제공처. 목록 결과의 info_service 를 그대로 넘긴다 (기본값: VALIDATION) |

### `search_job_postings`

고용24 채용공고를 검색합니다. Search job postings on 고용24 (formerly WorkNet).

**사업자등록번호로 바로 조회됩니다** — 어떤 회사가 지금 어떤 자리를, 얼마에 뽑는지 봅니다.
조건을 하나도 주지 않으면 전국 공고 전체(5만 건 이상)가 되므로 최소 하나는 필요합니다.
임금은 원 단위이며 max_salary 가 0이면 상한 미지정입니다. 상세 내용(담당 업무, 자격증,
기업 규모)은 wanted_auth_no 를 get_job_posting 에 넘기세요.

| 파라미터 | 타입 | 필수 | 기본값 | 설명 |
|---|---|---|---|---|
| `business_number` | string (optional) |  |  | 사업자등록번호 10자리 (하이픈 허용). 회사별 조회에 가장 정확하다 |
| `keyword` | string (optional) |  |  | 검색어. 공고 전반을 훑으므로 회사명으로 쓰면 무관한 공고도 섞인다 |
| `region_code` | string (optional) |  |  | 지역코드. 법정동코드 앞 5자리(예: 11680 강남구) 또는 10자리. 시도 전체는 11000 처럼. 모르면 nps 서버의 find_region_code 로 찾는다 |
| `occupation` | string (optional) |  |  | 직종 코드 6자리 (예: 155500 환경공학 기술자) |
| `min_pay` | integer (optional) |  |  | 최저 임금 하한 (원 단위 연봉, 예: 40000000) |
| `num_of_rows` | integer |  | `20` | 한 페이지 결과 수 (기본값: 20, 최대: 100) |
| `page_no` | integer |  | `1` | 페이지 번호 (기본값: 1) |
